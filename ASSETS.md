# Asset provenance

## Original work

The site names, copy, layout and interface code were created for this independent web-development portfolio. Objects uses generated product imagery adapted from real photographic references; it does not depict an existing seller's goods.

Project-preview images in `public/previews/` are screenshots of the implemented sites in this repository. They do not reproduce the reference websites.

## Restaurant photographs

See `src/table/ASSETS-table.md` for the original Unsplash photo pages, photographers and licence. The original files and photo-based content edits are served locally. The visible edited images preserve photographic style while changing scene or food content; original photographer links identify the reference sources.

## Objects photography

See `src/objects/ASSETS-objects.md` for the licensed Unsplash reference photographs, photographers, generated asset list and variant mapping. These are generated images adapted from photographic references, not the original source photographs. Original SVG studies remain in the source assets but are no longer displayed.

## Typography

The portfolio index loads [DM Sans](https://fonts.google.com/specimen/DM+Sans) and [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif) via Google Fonts. Both are distributed under the SIL Open Font License. System sans-serif and Georgia fallbacks remain available if the font service cannot load.

Objects also uses Libre Caslon Display (Google Fonts, SIL OFL), and Seasonal Table uses Playfair Display (Google Fonts, SIL OFL). The site-specific stylesheets document any additional fonts; no commercial font files are bundled.
